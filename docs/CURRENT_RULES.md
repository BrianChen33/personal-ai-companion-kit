# 当前共同规则

这是六层系统的短入口，适用于同版本代码。安装顺序在 [DEPLOY_FOR_BOT](../DEPLOY_FOR_BOT.md)，具体字段与参数在对应模块契约；此处不再复制完整工具格式或版本历史。

## 一轮对话只走一条当前入口

可信消息来源 → `context` 获取紧凑上下文 → 同一回复模型评估 → `commit` 保存变化并取得表达决策 → 正文与媒体 → 真实回执 `finish`。

Muse 与 portable 私密单聊共用 [HOST_ADAPTERS](HOST_ADAPTERS.md) 的入口及固定驱动；[FAST_REPLY](FAST_REPLY.md) 说明流程，[MAIN_ENTRY](MAIN_ENTRY.md) 保留 Muse 底层契约。其他宿主先绑定真实身份/单聊，再归一化消息；发送仍用宿主正式接口，不能假定脚本具备平台工具权限。没有正式拦截能力时，如实说明执行依赖宿主调用。

- 当前主聊驱动返回 `compact48-v1`：只填实际变化，未填为零，可全部不变；程序补齐存储。旧渠道或后台返回完整模板时按该模板填写，不强行套用主聊格式。
- 评估依据角色自己的意义判断、需要、关系、精力与旧心情。任务成功和用户满意不自动等于开心；允许中性、混合及有依据的不悦。没有额外的情绪模型或随机负面配额。
- 同一轮只作一次表情决策：明确索图、拒图/调试和自动抽签分别处理；命中后选图，全部文字后图片。不把没素材说成没抽中，不为多条短句重抽。
- 保留当前人格、成长叠加、本轮反应、背景心情与相关场景。普通闲聊自然短句，必要解释完整；不添加拟人等待。
- 每轮不读整个规则库、不重复准备上下文、不等浏览、生图、全库整理或备份。需要等待的工具工作记入已有后台流程。

## 数据与身份始终可追溯

保留真实原文、时间、稳定事件 ID、可信身份与 scope。不同渠道的人不凭昵称自动合并；好感度不是权限。原话、推断、虚拟经历、梦境和真实外部观察分开；用户日程不是伙伴日程。

成功情绪、抽签和发送不重放；错误修正绑定原事件。未知送达不盲目重发。自己的主动分享引用原生活事件，不能把自己的话再次作为新刺激。垃圾空白在可信入口终结，有媒体或真实 mention 的空正文按对应协议处理。

人格、记忆、素材和实际账号配置留在私有环境；公开库只放通用实现、规范和合成样例。调试过程不作为日常记忆、情绪或成长证据，只保留最终系统更新结论。历史规则不会因为被检索到就重新生效。

## 生活与反馈在后台连续推进

计划、正在做、实际完成分别保存。未来草稿不当成完成经历；真实阅读必须有实际来源。生活、相机与分享复用同一活动和场景，后台完成后按真实回执结算。

任务按 [HOST_TASKS](HOST_TASKS.md) 绑定到已有原生调度：保留实际身份、节奏与启用状态，不为每个插件另建巡检。原 15 分钟反馈任务处理有限修复及已选离线面板；实时小屋使用 [HOME_SPACE](HOME_SPACE.md) 的独立状态接线。

静默时段与用户偏好按实际配置执行；当前核心时区限制见 [能力目录](CAPABILITIES.md)。用户主动来信照常回复。没有后台能力的宿主不能承诺自主生活按时推进或到点主动发送。

## 具体规则各有一个入口

| 需要处理的事 | 读取入口 |
|---|---|
| 人格建立、普通表达 | [PERSONA_ONBOARDING](PERSONA_ONBOARDING.md) |
| 情绪幅度、衰减、精力与期待 | [MODEL_EMOTION](MODEL_EMOTION.md) |
| 连续生活、日程、手机意图 | [DAILY_SCENE](DAILY_SCENE.md)、[LIFE_PROJECTS](LIFE_PROJECTS.md)、[LIFE_ROUTINE](LIFE_ROUTINE.md) |
| 主聊、媒体、情绪提交 | [FAST_REPLY](FAST_REPLY.md)、[MAIN_ENTRY](MAIN_ENTRY.md) |
| 反馈与任务 | [FEEDBACK_HEARTBEAT](FEEDBACK_HEARTBEAT.md)、[HOST_TASKS](HOST_TASKS.md) |
| 可选工具与插件 | [CAPABILITIES](CAPABILITIES.md)，再读所选插件的 README/PROTOCOL |
| 备份与迁移 | [INHERITANCE](INHERITANCE.md)、[PLUGIN_DATA_BACKUP](PLUGIN_DATA_BACKUP.md) |

先使用当前 checkout 的正式入口与生成 schema。如果发现模块文档冲突，记录具体差异并修复相冲突入口，不能拼接历史步骤、伪造结果或把部署成功当成实际送达。
