# 能力目录与安装条件

适用 Kit 0.16.0 / runtime 2.11.1。这里列的是**公开仓库交付范围**，不是对某个账号、设备或平台的安装证明。当前只有四个独立插件目录；其余已有能力仍按模块接入。

## 先判断宿主能做什么

| 宿主条件 | 可以达到的范围 | 不能承诺的事 |
|---|---|---|
| 只有聊天窗口 | 阅读方案、设计人格 | 持久数据库、后台任务、自动提醒和主动生活 |
| Python 3.10+、SQLite FTS5、持久私有磁盘 | 核心状态、检索与按调用运行的六层流程 | 没有消息适配就不能自动接管聊天 |
| 再有 Node.js 与可信消息/发送接口 | Muse / portable 已认证主人单聊文字入口 | [HOST_ADAPTERS](HOST_ADAPTERS.md)；发送必须有真实接口，群聊/媒体输入需另行适配 |
| 再有后台执行/原生调度 | 连续生活、反馈、已选任务 | 定时检查不等于准点递送；提醒还需正式一次性任务 |
| 再有浏览器、生图、私有网页等 | 安装满足条件的可选能力 | 安装插件代码不自动获得账号、工具或数据权限 |

Node.js 的当前 CI 环境为 22；其他版本需实际验收。核心目前使用 UTC+8，其他时区尚需适配，不能只改提示词就声称全系统已切时区。纯聊天产品也不能仅凭导入提示词获得持久运行环境。

| 3D 小屋 | Three.js 前端 0.2.8＋状态接线协议 | 私有页面、WebGL、角色资产、状态接口 | [HOME_SPACE](HOME_SPACE.md)；角色模型另备，每个平台需验证存储/状态读取/访问范围 |

| 提醒 | 核心账本与宿主协作契约 | 原生 runonce、取消/改期与真实发送 | [HOST_TASKS](HOST_TASKS.md)；定时轮询不替代准点入口 |
| 私有备份与继承 | 原格式快照发布器与插件快照登记 | 用户指定的 PRIVATE 仓库与正式写入授权 | [GITHUB_VAULT](GITHUB_VAULT.md)、[插件数据](PLUGIN_DATA_BACKUP.md)；凭据、原始健康库和可重建缓存不默认迁移 |

## 尚未作为完整能力交付

| 项目 | 状态 | 安装时的处理 |
|---|---|---|
| B 站、抖音自动阅读 | 预留接口；完整 provider 未实现 | 保持停用，不能当成已经能刷视频 |
| 通用邮件、用户日程、招聘管理插件 | 方案或用户特定应用，未发布完整可安装包 | 单独评估，不把某个私人部署当成公共插件 |
| 通用消息适配 v1 | 已实现并做隔离验收；仅主人私密文字单聊 | [HOST_ADAPTERS](HOST_ADAPTERS.md)，第二个真实宿主尚未部署验收 |
| 跨平台工具连接器、MCP 安装入口 | 后续研发；当前没有统一工具绑定器 | 根据真实宿主逐项适配，不编造一键命令 |
| 自动安装向导、自动断点续装 | 尚未实现 | 现阶段由 Agent 按部署手册记录/读回步骤 |
| 全部能力独立插件化 | 分阶段推进；本版仅入口整理 | 不在用户安装过程中执行研发重构 |
| 第二个平台完整空白安装认证 | 未完成 | 不宣传“任意个人 AI 助理开箱即用” |

## 首次选择与费用

先确认新建、升级或继承，再展示四组可选能力：聊天渠道；生活与表达；个人工具；查看与迁移。用户可选“只装核心”或点选功能。已有明确选择不重复询问；未选插件不安装、不调网络。

只追问所选能力缺少的条件：人格、阅读许可来源、角色图、账号授权、钱包/币种或私库地址。安装权限不会从网页、记忆、关系分数或旧配置中自动产生。

仓库本身不收服务费，但宿主、模型、存储与外部 API 可能有费用。用户要求无超额风险时，必须核实提供方是否有硬上限或停用机制；无法证明就保持该外部服务未接入，不能把免费额度等同于零超额风险。
