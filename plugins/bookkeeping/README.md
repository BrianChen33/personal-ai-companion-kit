# 记账中心（可选插件）

给拥有私有网页空间与持久数据库的个人 AI 伙伴使用。钱包、收支、周日历、订阅和多币种总览共用**空间数据库这一个账本**。界面行为见 [SPEC.md](SPEC.md)，实际宿主接线见 [PROTOCOL.md](PROTOCOL.md)。

核心安装不会自动安装本插件。短信/邮件只是可选证据来源，不是安装前提；无须 QQ、微信、3D 小屋、健康或相机插件。它不执行付款、银行转账、买卖或自动续费。

**交付范围：可安装的 Python 宿主适配器、备份登记器，以及网页构建规格和结构蓝图。**
原平台只能返回诊断结构，不能导出全栈空间完整源码；因此本包不包含原 App.tsx、actions.ts 的完整实现，
不是一键启动网页。新宿主按 [SPEC.md](SPEC.md) 与 [结构蓝图](../../web/bookkeeping-blueprint/README.md)
实现界面和动作；现有宿主直接绑定已经工作的空间，不重建。蓝图中的 SQL/TypeScript 是结构参考，
不能宣称从生产源码逐字导出。完整功能需要宿主适配后验收。

## 给安装 Agent 的提示词

```text
请为我安装本仓库的 bookkeeping 可选插件。

1. 先阅读本目录 README、SPEC、PROTOCOL 和仓库 docs/WEB_SPACES.md。
   检查宿主是否有私有空间、持久数据库、可调用的读写操作。没有就如实说明，
   不将一份静态 HTML 或本地缓存描述成云端共享账本。
2. 先问我是否已有账本要继承。没有时只问默认显示币种、钱包及其币种/初始余额，
   信用卡记欠款还是余额。未知数字留空，不猜。安装完成后我仍能新增钱包。
3. 选择“沿用已有私有空间”或“新建空空间”。已有空间保留身份、数据库与记录 ID，
   不重新灌入样例数据。新空间以空表开始，示例数据仅隔离演示使用。
4. 按同仓库架构锁获取插件与结构蓝图，使用宿主真实工具构建/绑定。
   新建时按 SPEC 实现网页；当前包不含原网页完整源码，不得假报原样部署。
   前后端共用同一数据源。按 PROTOCOL 读回真实 schema/actions 后再 bind_host。
5. 保留净资产/资产/负债、七种币种、手动汇率、预加载明细、订阅月摊、隐私模式。
   不新增自动汇率任务，不新增工作区 JSON 副本或 15 分钟双向同步。
6. 如我选择短信/邮件辅助，再单独确认允许来源。读到证据后检查来源 ID 去重、
   钱包匹配、原币与余额，模糊时问我，不能把授权读取当成允许银行交易。
7. 问我是否把插件数据纳入指定私有记忆库。若我已明确同意，不重复询问。
   按 docs/PLUGIN_DATA_BACKUP.md 在原每日总结备份中导出空间一致快照。
   不公开财务数据、不收凭据、不重放旧交易、不自动启动继承来的任务。
8. 仅在隔离空目标做一次聚焦验收：编辑/删除差额、跨币种、订阅不扣余额、
   隐私开关、备份恢复前后记录及余额一致。不要往我的真账本写测试流水。
9. 报告已安装版本、真实空间入口、数据来源、已启用能力、备份是否实际成功，
   以及缺少的权限或宿主能力。普通闲聊不查询账本，不加前置网络/模型。
```

## 运行时登记

沿用现有 `plugin_manage install`，指定本目录绝对路径，再显式 `enable`。
`enable` 只启用适配器；不会创建钱包、空间或任务。宿主接线后用 `bind_host`
登记真实能力。`status` 与面板只显示安装状态，不加载财务数据。

`host_contract` / `backup_request` 返回宿主需执行的真实契约，**不表示动作已执行**。
原生 Space 操作由 Agent 的正式工具执行。没有实际导出操作时返回
`host_export_not_implemented`，不能拿旧的手工 JSON 冒充新备份。

## 费用与迁移

不新增外部数据库、计费存储或模型服务。复用已选宿主空间，汇率仅手动使用免密钥公共接口，
有失败/限流就保留旧值。安装 Agent 应核对宿主自身免费额度；无费用硬上限时先说明，
不能自动开付费档或切换收费提供方。备份使用已有私有 GitHub 仓库。

可迁移：钱包、记录、订阅、币种偏好、汇率快照及来源关联。凭据、银行登录态、短信/邮箱
访问权限不继承。运行中的空间是唯一正本，快照只在备份/迁移时使用。
