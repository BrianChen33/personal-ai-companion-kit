# 记账中心最终行为

来源：用户已接受的私人空间需求与最终修正。以下仅包含通用行为，无真实个人账目。

- 顶部居中大字为**净资产**，下方并排**资产**与**负债**。负余额（含信用卡欠款）计入负债，不能把可用额度当存款。金额按统一精度显示，计算不靠模型口算。
- 币种选择覆盖 CNY（界面可标人民币/RMB）、HKD、USD、GBP、EUR、SGD、TWD，所有选择器一致。钱包与单笔流水保留原币；总览、月汇总、日历与订阅月成本用选定显示币种。
- “货币设置”按钮仅显示这四字；居中弹窗含自定义币种下拉、手动刷新汇率和以显示币种为基准的汇率。下拉有轻微淡入下滑、箭头旋转、选项高亮；支持键盘/Esc/外点关闭。缺汇率不能按 1:1 或零计入；保留最后有效汇率及日期。
- 汇率只由用户手动刷新；无每日自动更新任务。调用不需要付费账户的公共汇率端点，失败保留旧值，不切换计费服务。
- 月收入、支出卡可打开本月明细，按日期倒序；有月份切换。日历默认当前周、左右翻周、按周标题打开全年选择；按净收支红绿深浅显示，点日期即时开明细。
- 已加载周/月的明细本地展开，避免点一次再等远端请求。钱包明细/记一笔/余额修正/编辑/删除均使用同一持久数据库。
- 记录可改备注、金额、收支方向、钱包、日期；编辑按差额调整余额，换钱包先撤销旧影响再应用新影响。删除需明确确认并撤销相应余额影响；余额修正不能伪造成收入。
- 可添加钱包：名称、原币与初始余额。初始化不预置某个用户的钱包，也不在页面更新时重新初始化或覆盖旧数据。
- 钱包下方是订阅区，“本月订阅支出（折算）”。支持每月、每年、一次性，覆盖月数、起止日期、每月续费日、备注。一次性费用按实际覆盖月数摊分。订阅成本展示不会自动扣钱包或再生成一笔已存在的支付流水。
- 页面打开读取空间数据库；打开期间每 5 秒轻量比较变化标识，有变再刷新，主动保存成功立刻更新。页面不直接扫描手机短信或邮箱；Agent 读到已授权证据后才通过同一空间操作写入。来源 ID 去重，不重复记账。
- “隐私模式”按钮不显示“开/关”文字，以高光和 aria-pressed 表达状态。金额显示 XX.XX，关闭卡片详情入口；进入隐私模式时关闭已打开的金额详情。订阅说明中的原始金额、周期、续费日与备注按用户选择保留；右侧折算金额和订阅合计仍遮盖。此功能仅是屏幕遮挡，不是访问控制。
- 运行数据库只有空间内一份。已取消的工作区 wallets.json / subscriptions.json 双向副本与 15 分钟同步任务不得恢复。
- 新 Agent 安装时询问钱包/币种/负债记法及是否启用短信或邮件辅助；不得默认读取账户，更不得执行支付、交易或转账。
